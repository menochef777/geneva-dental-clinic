# Geneva Dental Clinic — Landing Page

Modern, high-converting institutional landing page for Geneva Dental Clinic featuring Swiss dental excellence, interactive 3D frame scroll animation, bilingual (FR/EN) support, clinic room tour video, interactive Google Maps location switchers, and appointment booking modal.

## 🇨🇭 Features
- **Hero & 3D Scroll Canvas**: Canvas animation synchronized with user scroll.
- **Bilingual Interface**: Seamless instant toggle between French (FR) and English (EN).
- **Institutional Authority (Section 5)**: Clinic video tour, Swiss technology highlights, and pain-free care protocols.
- **ScrollStack Expertise**: Interactive layered cards for Aesthetic Dentistry, Implantology, Orthodontics, and Preventive Care.
- **Dual Clinic Locations**: Interactive switcher for Rue Saint Léger and Rue Prévost-Martin.
- **Verified Patient Reviews**: Testimonials carousel/grid.
- **FAQ Accordion & Consultation Modal**: Direct consultation requests and WhatsApp integration.

## 🚀 Getting Started

### Local Server
Run with Node.js:
```bash
node server.js
```
Then visit [http://localhost:8080](http://localhost:8080).
